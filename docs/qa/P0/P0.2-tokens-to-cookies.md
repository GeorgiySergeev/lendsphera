````markdown
## 🎯 ПРОБЛЕМА

### Текущее состояние (危險):

```typescript
// apps/web/stores/auth-store.ts
const useAuthStore = create()(
  persist(
    (set) => ({
      accessToken: null,
      refreshToken: null, // ⚠️ В localStorage НАВСЕГДА
      user: null
      // ...
    }),
    {
      name: "landing-builder-auth",
      storage: createJSONStorage(() => window.localStorage)
    }
  )
);
```
````

**Проблема:**

- XSS на editor (GrapesJS + Monaco + user CSS) → один `eval()` украсть tokens
- localStorage читается любым JS: `localStorage.getItem('landing-builder-auth')`
- Refresh token на 30 дней → полный доступ к аккаунту на месяц

### Оптимальная схема

```
refresh token  → HttpOnly Secure SameSite=Lax cookie (недоступна JS)
access token   → память (теряется при F5, но OK - есть refresh token в cookie)
user profile   → localStorage (некритично, только публичные данные)
```

### 1.2 Обнови login endpoint

**БЫЛО:**

```typescript
@Post('login')
async login(@Body() dto: LoginDto) {

}
```

**СТАЛО:**

```typescript
import { Response } from 'express';
import { Res } from '@nestjs/common';

@Post('login')
async login(
  @Body() dto: LoginDto,
  @Res({ passthrough: true }) response: Response
) {
  const { user, accessToken, refreshToken } = await this.authService.login(dto);

  // Установи refresh token в HttpOnly cookie
  response.cookie('refreshToken', refreshToken, {
    httpOnly: true,                    // Недоступна JavaScript
    secure: process.env.NODE_ENV === 'production',  // Только HTTPS в prod
    sameSite: 'lax',                   // Защита от CSRF (но не полный, еще нужна другая защита)
    maxAge: 30 * 24 * 60 * 60 * 1000,  // 30 дней
    path: '/',                         // Доступна на всех путях
  });

  // Access token можешь вернуть в body (он недолгий — 15 мин)
  // или в Set-Cookie (но потом нужно в JS получить из response header)
  return {
    accessToken,           // Это передаст клиент в Authorization: Bearer
    user: {
      id: user.id,
      email: user.email,
      name: user.name,
      // НЕ включай tokens в response!
    }
  };
}
```

### 1.3 Обнови refresh endpoint

```typescript
import { Req } from '@nestjs/common';
import { Request } from 'express';

@Post('refresh')
async refresh(
  @Req() request: Request,
  @Res({ passthrough: true }) response: Response
) {
  // Получи refreshToken из cookie (express автоматически парсит)
  const oldRefreshToken = request.cookies.refreshToken;

  if (!oldRefreshToken) {
    throw new UnauthorizedException('Refresh token not found in cookies');
  }

  const { accessToken, refreshToken: newRefreshToken } =
    await this.authService.refresh(oldRefreshToken);

  // Обнови refresh token в cookie
  response.cookie('refreshToken', newRefreshToken, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    maxAge: 30 * 24 * 60 * 60 * 1000,
    path: '/',
  });

  return {
    accessToken,
    // refreshToken НЕ в body, она уже в cookie
  };
}
```

### 1.4 Обнови logout

```typescript
@Post('logout')
@UseGuards(JwtAuthGuard)
async logout(@Res({ passthrough: true }) response: Response) {
  // Удали cookie (установи максимально старую дату)
  response.clearCookie('refreshToken', {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    path: '/',
  });

  return { message: 'Logged out successfully' };
}
```

**СТАЛО:**

```typescript
type AuthState = {
  /**
   * Access token stored in MEMORY ONLY (lost on page refresh).
   * This is OK because:
   * 1. It's short-lived (15 minutes)
   * 2. Refresh token in HttpOnly cookie can get a new one
   * 3. Never exposed to XSS (not in localStorage)
   */
  accessToken: string | null;

  /**
   * Refresh token is in HttpOnly cookie (managed by browser).
   * NOT stored here. We only track if user is "logged in".
   */
  user: AuthUser | null;

  // Actions
  setAccessToken: (token: string) => void;
  setSession: (user: AuthUser, accessToken: string) => void;
  clearSession: () => void;
  isLoggedIn: () => boolean;
};

export const useAuthStore = create<AuthState>()(
  persist(
    (set, get) => ({
      accessToken: null, // Memory only
      user: null,

      setAccessToken: (accessToken: string) => set({ accessToken }),

      setSession: (user: AuthUser, accessToken: string) => set({ user, accessToken }),

      clearSession: () => set({ accessToken: null, user: null }),

      isLoggedIn: () => get().user !== null
    }),
    {
      name: "landing-builder-auth",
      // ⚠️ ВАЖНО: Тільки user в persist, НЕ tokens!
      partialize: ({ user }) => ({ user }),
      storage: createJSONStorage(() => window.localStorage)
    }
  )
);
```

## 📋 ШАГ 3: Обновить API Client

### 3.1 Создай/обнови API client для автоматического добавления accessToken

**Файл:** `apps/web/lib/api-client.ts` (создать если нет)

```typescript
import axios, { AxiosInstance, InternalAxiosRequestConfig } from "axios";
import { useAuthStore } from "@/stores/auth-store";

const API_BASE_URL = process.env.NEXT_PUBLIC_API_URL || "http://localhost:4000";

class ApiClient {
  private client: AxiosInstance;
  private isRefreshing = false;
  private failedQueue: Array<{
    resolve: (token: string) => void;
    reject: (error: Error) => void;
  }> = [];

  constructor() {
    this.client = axios.create({
      baseURL: API_BASE_URL,
      withCredentials: true // ✅ Отправляй cookies!
    });

    // ============ REQUEST INTERCEPTOR ============
    // Добавь accessToken к каждому запросу
    this.client.interceptors.request.use((config) => {
      const { accessToken } = useAuthStore.getState();

      if (accessToken) {
        config.headers.Authorization = `Bearer ${accessToken}`;
      }

      return config;
    });

    // ============ RESPONSE INTERCEPTOR ============
    // Если 401 → попробуй refreshToken
    this.client.interceptors.response.use(
      (response) => response,
      async (error) => {
        const originalRequest = error.config as InternalAxiosRequestConfig & {
          _retry?: boolean;
        };

        if (error.response?.status === 401 && !originalRequest._retry) {
          // Если уже пытались refresh → не пытайся еще раз
          if (this.isRefreshing) {
            return new Promise((resolve, reject) => {
              this.failedQueue.push({ resolve, reject });
            }).then((token) => {
              originalRequest.headers.Authorization = `Bearer ${token}`;
              return this.client(originalRequest);
            });
          }

          this.isRefreshing = true;

          try {
            // Отправь refresh запрос
            // refreshToken автоматически в cookie (withCredentials: true)
            const response = await this.client.post("/auth/refresh");
            const { accessToken } = response.data;

            const { setAccessToken } = useAuthStore.getState();
            setAccessToken(accessToken);

            // Retry все ожидающие запросы с новым accessToken
            this.failedQueue.forEach(({ resolve }) => resolve(accessToken));
            this.failedQueue = [];

            originalRequest._retry = true;
            originalRequest.headers.Authorization = `Bearer ${accessToken}`;
            return this.client(originalRequest);
          } catch (refreshError) {
            // Refresh failed → logout
            const { clearSession } = useAuthStore.getState();
            clearSession();

            this.failedQueue.forEach(({ reject }) => reject(refreshError));
            this.failedQueue = [];

            // Redirect to login
            window.location.href = "/login";
            return Promise.reject(refreshError);
          } finally {
            this.isRefreshing = false;
          }
        }

        return Promise.reject(error);
      }
    );
  }

  get instance() {
    return this.client;
  }
}

export const apiClient = new ApiClient().instance;
```

## 📋 ШАГ 5: Обновить middleware для авторизации

### 5.1 Если используешь fetch (не axios)

**Файл:** `apps/web/lib/fetch-client.ts`

```typescript
export async function fetchAPI(url: string, options: RequestInit = {}) {
  const { accessToken } = useAuthStore.getState();

  const headers: HeadersInit = {
    "Content-Type": "application/json",
    ...options.headers
  };

  if (accessToken) {
    headers["Authorization"] = `Bearer ${accessToken}`;
  }

  const response = await fetch(`${process.env.NEXT_PUBLIC_API_URL}${url}`, {
    ...options,
    headers,
    credentials: "include" // ✅ Отправляй cookies!
  });

  // Если 401 → попробуй refresh (аналогично axios interceptor)
  if (response.status === 401) {
    // Refresh token в cookie → браузер автоматически отправит
    const refreshResponse = await fetch(
      `${process.env.NEXT_PUBLIC_API_URL}/auth/refresh`,
      {
        method: "POST",
        credentials: "include"
      }
    );

    if (refreshResponse.ok) {
      const { accessToken: newAccessToken } = await refreshResponse.json();
      useAuthStore.getState().setAccessToken(newAccessToken);

      // Retry оригинальный запрос
      headers["Authorization"] = `Bearer ${newAccessToken}`;
      return fetch(`${process.env.NEXT_PUBLIC_API_URL}${url}`, {
        ...options,
        headers,
        credentials: "include"
      });
    } else {
      // Refresh failed → logout
      useAuthStore.getState().clearSession();
      window.location.href = "/login";
    }
  }

  return response;
}
```

## 🚨 ВОЗМОЖНЫЕ ОШИБКИ

| Ошибка                                                                                             | Причина                                      | Решение                                                   |
| -------------------------------------------------------------------------------------------------- | -------------------------------------------- | --------------------------------------------------------- |
| Cookie не устанавливается в браузер                                                                | `secure: true` на localhost (HTTPS required) | Используй `process.env.NODE_ENV === 'production'` условие |
| "SameSite attribute flavor must be one of lax, strict or none"                                     | Неправильное значение sameSite               | Используй lowercase: `sameSite: 'lax'`                    |
| 401 после login (token rejected)                                                                   | accessToken из response не сохранен в state  | Убедись `setAccessToken()` вызывается после login         |
| CORS error "credentials mode is 'include', but Access-Control-Allow-Credentials header is missing" | CORS не разрешает credentials                | Убедись P0.1 правильно установлен (`credentials: true`)   |
| Cookies empty после page reload                                                                    | accessToken в памяти теряется (это OK)       | Используй refreshToken из cookie для восстановления       |
