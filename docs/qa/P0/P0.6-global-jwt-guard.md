## 🎯 ПРОБЛЕМА

### Текущее состояние (危險):

```typescript
// apps/api/src/landings/landings.controller.ts
@Controller('landings')
export class LandingsController {
  @Get()
  @UseGuards(JwtAuthGuard)  // ← Must remember every time!
  async list() { }

  @Get(':id')
  @UseGuards(JwtAuthGuard)  // ← Must remember
  async get() { }

  @Post()
  // ⚠️ ЗАБУВ! Developer forgets @UseGuards
  async create() { }  // ← UNAUTHENTICATED ACCESS!

  @Patch(':id')
  // @UseGuards(JwtAuthGuard)  // ← Accidentally commented
  async update() { }  // ← UNAUTHENTICATED ACCESS!
}
````

**Проблема:**

- Легко забыть `@UseGuards(JwtAuthGuard)` на новом endpoint
- Default behavior = public access (dangerous)
- Лучше наоборот: all protected by default, opt-out с `@Public()`

```typescript
import { SetMetadata } from "@nestjs/common";

/**
 * Decorator to mark an endpoint as public (no JWT required).
 *
 * Usage:
 * @Get()
 * @Public()
 * async getPublic() { }
 */
export const PUBLIC_KEY = "isPublic";

export const Public = () => SetMetadata(PUBLIC_KEY, true);
```

### 2.2 Обнови guard чтобы он проверял @Public()

**БЫЛО:**

```typescript
import { Injectable } from "@nestjs/common";
import { AuthGuard } from "@nestjs/passport";

@Injectable()
export class JwtAuthGuard extends AuthGuard("jwt") {}
```

**СТАЛО:**

```typescript
import {
  Injectable,
  CanActivate,
  ExecutionContext,
  UnauthorizedException
} from "@nestjs/common";
import { Reflector } from "@nestjs/core";
import { AuthGuard } from "@nestjs/passport";
import { PUBLIC_KEY } from "@/common/public.decorator";

@Injectable()
export class JwtAuthGuard extends AuthGuard("jwt") implements CanActivate {
  constructor(private reflector: Reflector) {
    super();
  }

  canActivate(context: ExecutionContext): any {
    // ============ CHECK IF ENDPOINT IS MARKED AS PUBLIC ============
    const isPublic = this.reflector.getAllAndOverride<boolean>(PUBLIC_KEY, [
      context.getHandler(),
      context.getClass()
    ]);

    // If endpoint is marked as @Public() → skip JWT check
    if (isPublic) {
      return true;
    }

    // ============ OTHERWISE, REQUIRE JWT ============
    // Call parent's canActivate() which runs Passport JWT strategy
    return super.canActivate(context);
  }

  handleRequest(err: any, user: any, info: any) {
    if (err || !user) {
      throw err || new UnauthorizedException("Invalid or missing JWT token");
    }
    return user;
  }
}
```

### 3.2 Добавь глобальный JWT guard

**БЫЛО:**

```typescript
import { Module } from "@nestjs/common";
import { APP_GUARD } from "@nestjs/core";
import { ThrottlerGuard } from "@nestjs/throttler";

@Module({
  imports: [
    // ...
  ],
  providers: [
    {
      provide: APP_GUARD,
      useClass: ThrottlerGuard // Only throttler guard
    }
  ]
})
export class AppModule {}
```

**СТАЛО:**

```typescript
import { Module } from "@nestjs/common";
import { APP_GUARD } from "@nestjs/core";
import { ThrottlerGuard } from "@nestjs/throttler";
import { JwtAuthGuard } from "@/auth/jwt-auth.guard";

@Module({
  imports: [
    // ...
  ],
  providers: [
    // ============ THROTTLE GUARD (rate limiting) ============
    {
      provide: APP_GUARD,
      useClass: ThrottlerGuard
    },

    // ============ JWT GUARD (authentication) ============
    // This is applied AFTER throttler
    // All endpoints require JWT unless marked with @Public()
    {
      provide: APP_GUARD,
      useClass: JwtAuthGuard
    }
  ]
})
export class AppModule {}
```

**⚠️ Важно:** Порядок matters! ThrottlerGuard должен идти ДО JwtAuthGuard (каждый guard вызывается по порядку).

## 🚨 ВОЗМОЖНЫЕ ОШИБКИ

| Ошибка                                                    | Причина                                | Решение                                                    |
| --------------------------------------------------------- | -------------------------------------- | ---------------------------------------------------------- |
| 401 на endpoint, который является публичным               | @Public() не добавлен                  | Найди endpoint в controller и добавь @Public()             |
| All endpoints require JWT (даже health check)             | Guard зарегистрирован но нет @Public() | Добавь @Public() к health контроллeру                      |
| "Cannot read property \'getAllAndOverride\' of undefined" | Reflector не injected в guard          | Добавь `constructor(private reflector: Reflector)` в guard |
| UnauthorizedError не выбрасывается                        | handleRequest не вызывается            | Убедись что `extends AuthGuard('jwt')` правильно           |
