## 📋 ШАГ 1: Создай composite action

### 1.1 Директория

```bash
mkdir -p .github/actions/setup-env
```

### 1.2 Создай action.yml

**Файл:** `.github/actions/setup-env/action.yml`

```yaml
name: "Setup Environment"
description: "Setup Node.js, pnpm, and install dependencies"

inputs:
  node-version:
    description: "Node.js version"
    required: false
    default: "22.x"

  pnpm-version:
    description: "pnpm version"
    required: false
    default: "10.32.1"

  registry-url:
    description: "NPM registry URL (for private packages)"
    required: false
    default: "https://registry.npmjs.org"

runs:
  using: "composite"

  steps:
    - name: Setup Node.js
      uses: actions/setup-node@v4
      with:
        node-version: ${{ inputs.node-version }}
        registry-url: ${{ inputs.registry-url }}

    - name: Setup pnpm
      uses: pnpm/action-setup@v4
      with:
        version: ${{ inputs.pnpm-version }}

    - name: Get pnpm store directory
      id: pnpm-cache
      shell: bash
      run: |
        echo "STORE_PATH=$(pnpm store path --silent)" >> $GITHUB_OUTPUT

    - name: Setup pnpm cache
      uses: actions/cache@v4
      with:
        path: ${{ steps.pnpm-cache.outputs.STORE_PATH }}
        key: ${{ runner.os }}-pnpm-store-${{ hashFiles('**/pnpm-lock.yaml') }}
        restore-keys: |
          ${{ runner.os }}-pnpm-store-

    - name: Install dependencies
      shell: bash
      run: pnpm install --frozen-lockfile

    - name: Verify environment
      shell: bash
      run: |
        echo "Node: $(node --version)"
        echo "pnpm: $(pnpm --version)"
        echo "npm: $(npm --version)"
```

### 2.2 Обновить для использования composite action

**БУЛО:**

```yaml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: "22.x"

      - uses: pnpm/action-setup@v4
        with:
          version: 10.32.1

      - run: pnpm install --frozen-lockfile

      - run: pnpm run typecheck

      - run: pnpm run lint

      - run: pnpm run test

      - run: pnpm run build
```

**СТАЛО:**

```yaml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

jobs:
  typecheck:
    name: TypeCheck
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      # ✅ Use composite action
      - uses: ./.github/actions/setup-env

      - run: pnpm run typecheck

  lint:
    name: Lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      # ✅ Use composite action (same setup always)
      - uses: ./.github/actions/setup-env

      - run: pnpm run lint

  test:
    name: Unit Tests
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      # ✅ Use composite action
      - uses: ./.github/actions/setup-env

      - run: pnpm run test

  build:
    name: Build
    runs-on: ubuntu-latest
    needs: [typecheck, lint, test] # Only build if all pass
    steps:
      - uses: actions/checkout@v4

      # ✅ Use composite action (same setup)
      - uses: ./.github/actions/setup-env

      - run: pnpm run build

      - name: Upload build artifacts
        uses: actions/upload-artifact@v4
        with:
          name: build-artifacts
          path: dist/

  docker-build:
    name: Docker Build
    runs-on: ubuntu-latest
    needs: [build]
    if: github.event_name == 'push' && github.ref == 'refs/heads/main'
    steps:
      - uses: actions/checkout@v4

      # ✅ Docker build (minimal setup, no pnpm needed)
      - uses: docker/setup-buildx-action@v3

      - name: Build Docker image
        uses: docker/build-push-action@v5
        with:
          context: .
          file: Dockerfile
          push: false
          tags: lendsphera:latest
```

**СТАЛО:**

```yaml
name: E2E Tests

on:
  schedule:
    - cron: "0 2 * * *" # Run daily at 2 AM

  workflow_run:
    workflows: ["CI"]
    types: [completed]
    branches: [main]

jobs:
  e2e:
    name: E2E Tests (Playwright)
    runs-on: ubuntu-latest

    # Only run if CI workflow succeeded
    if: ${{ github.event.workflow_run.conclusion == 'success' || github.event_name == 'schedule' }}

    services:
      postgres:
        image: postgres:16
        env:
          POSTGRES_PASSWORD: postgres
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5
        ports:
          - 5432:5432

      redis:
        image: redis:7
        options: >-
          --health-cmd "redis-cli ping"
          --health-interval 10s
        ports:
          - 6379:6379

    steps:
      - uses: actions/checkout@v4

      # ✅ Use composite action (SAME as ci.yml)
      - uses: ./.github/actions/setup-env

      - name: Start API server
        run: pnpm --filter @workspace/api dev &
        env:
          DATABASE_URL: postgresql://postgres:postgres@localhost:5432/lendsphera_test
          REDIS_URL: redis://localhost:6379

      - name: Start Web editor
        run: pnpm --filter @workspace/web dev &

      - name: Start Runtime
        run: pnpm --filter @workspace/runtime dev &

      - name: Wait for services
        run: |
          npx wait-on http://localhost:4000/health \
                        http://localhost:3002 \
                        http://localhost:3001 \
                        --timeout 30000

      - name: Run Playwright E2E tests
        run: pnpm run e2e
        env:
          TEST_USER_EMAIL: ${{ secrets.TEST_USER_EMAIL }}
          TEST_USER_PASSWORD: ${{ secrets.TEST_USER_PASSWORD }}

      - name: Upload test results
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: e2e-results
          path: playwright-report/

      - name: Comment on PR
        if: github.event_name == 'pull_request' && always()
        uses: actions/github-script@v7
        with:
          script: |
            const conclusion = ${{ job.status == 'success' }} ? '✅ E2E tests passed' : '❌ E2E tests failed';
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: `${conclusion}\n\nArtifacts: [playwright-report](../actions/runs/${{ github.run_id }})`
            });
```

## 🚨 ВОЗМОЖНЫЕ ОШИБКИ

| Ошибка                    | Причина                                     | Решение                                        |
| ------------------------- | ------------------------------------------- | ---------------------------------------------- |
| "Cannot find action"      | Composite action не в правильной директории | Проверь путь `./.github/actions/setup-env`     |
| pnpm lockfile несовместим | Разные версии pnpm в разных workflows       | Используй composite action для консистентности |
| E2E тесты timeout         | Services не ready                           | Увели `wait-on --timeout` value                |
| Artifact upload fails     | Путь не существует                          | Убедись что `pnpm run build` создает `dist/`   |
