# Phase 0 · Step 3 — OpenAPI and API client

## Context

`apps/api` is NestJS + Prisma. We need a Swagger/OpenAPI 3.1 spec generated from
Nest decorators, and a `@lendsphera/api-client` package so that `apps/web` and
`apps/runtime` never write raw `fetch` calls.

## Goal

Running `pnpm openapi:sync` from repo root regenerates `openapi/openapi.json`
and the typed TS client in `packages/api-client/src/generated/`.

## Inputs

Read these before writing any code:

```bash
# 1. Does @nestjs/swagger already exist?
```

### `apps/api/scripts/export-openapi.ts`

CLI — boots Nest in app-context mode (no HTTP), writes spec to repo root.

```typescript
import { NestFactory } from "@nestjs/core";
import { SwaggerModule, DocumentBuilder } from "@nestjs/swagger";
import { writeFileSync, mkdirSync } from "node:fs";
import { join } from "node:path";
import { AppModule } from "../src/app.module";

async function main() {
  const app = await NestFactory.create(AppModule, { logger: false });

  const config = new DocumentBuilder()
    .setTitle("Lendsphera API")
    .setVersion("1.0")
    .addBearerAuth()
    .build();

  const document = SwaggerModule.createDocument(app, config);
  const outDir = join(__dirname, "..", "..", "..", "openapi");

  mkdirSync(outDir, { recursive: true });
  writeFileSync(
    join(outDir, "openapi.json"),
    JSON.stringify(document, null, 2)
  );
  console.log("✓ openapi/openapi.json written");
  await app.close();
}

main().catch((e) => {
  console.error(e);
  process.exit(1);
});
```

### `packages/api-client/src/auth-fetch.ts`

```typescript
// Wraps the generated client's fetch with JWT injection + 401 auto-refresh.
// Import session utilities from Auth.js (apps/web) or pass token explicitly.
export function createAuthClient(getToken: () => Promise<string | null>) {
  return {
    async fetch(url: string, init?: RequestInit): Promise<Response> {
      const token = await getToken();
      const headers = new Headers(init?.headers);
      if (token) headers.set("Authorization", `Bearer ${token}`);

      const res = await fetch(url, { ...init, headers });

      if (res.status === 401) {
        // caller is responsible for refresh logic (apps/web uses Auth.js)
        throw new Error("Unauthorized — token refresh required");
      }
      return res;
    }
  };
}
```

### Root `package.json` — add to `"scripts"`

```json
"openapi:export":  "pnpm --filter <api-package-name> exec tsx scripts/export-openapi.ts",
"openapi:generate": "pnpm --filter @lendsphera/api-client generate",
"openapi:sync":    "pnpm openapi:export && pnpm openapi:generate",
"openapi:check":   "pnpm openapi:export && git diff --exit-code openapi/openapi.json"
```

Replace `<api-package-name>` with the value from `apps/api/package.json`
`"name"`.

## Acceptance criteria

- `pnpm openapi:sync` completes without error.
- `openapi/openapi.json` is written and contains `"title": "Lendsphera API"`.
- `packages/api-client/src/generated/` contains typed service methods.
- `GET /v1/health` returns `{ status: 'ok', ts: '...' }`.
- `GET /v1/openapi.json` returns the spec JSON.
- In dev: Swagger UI opens at `http://localhost:<port>/v1/docs`.
- `pnpm openapi:check` exits non-zero when spec is stale (CI guard).
- `pnpm -r typecheck` passes after `openapi:sync`.

## Out of scope

- Real resource endpoints (Phase 1).
- Auth headers wired into the client (Step 0.4).
