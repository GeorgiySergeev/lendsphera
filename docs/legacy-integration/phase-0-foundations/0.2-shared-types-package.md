# Phase 0 · Step 2 — Shared types package

## Context

`packages/types` exists but is empty. We need a single source of TS types
consumed by `apps/web`, `apps/api`, `apps/runtime`, and `packages/widgets`.

Types must reflect the **real schema** (no Workspace, real field names from
Landing/Geo/Product/Price — in particular `geoId` not `geoCode`).

## Goal

Populate `packages/types` with hand-written API-contract types (not Prisma
client types — those stay internal to `apps/api`) and make every workspace
import from `@lendsphera/types`.

## Inputs

Before coding, read:

- `apps/api/prisma/schema.prisma` — canonical field names
- `packages/types/package.json` — check current name, exports, build tool
- Look up `Role` enum values:
  `grep -A 10 '^enum Role' apps/api/prisma/schema.prisma`
- Look up `LandingStatus` values: `grep -A 10 '^enum LandingStatus' ...`
- Look up `LandingOrigin` / `LegacySource` values (used in runtime-vars)

## Files to create or modify

### `packages/types/src/landing.ts`

```typescript
// LandingContext is the single merged payload emitted by LandingContextResolver
// and consumed by apps/runtime for rendering.
//
// Merge order (lowest → highest priority):
//   Template.placeholders.defaults
//     → I18nString by lang
//       → Product fields
//         → active Price for (productId, geoId)
//           → Landing.settings.overrides

export type LandingContext = {
  // identity
  landingId: string;
  slug: string;
  geoId: string;
  lang: string; // from Geo
  dir: "ltr" | "rtl"; // from Geo

  // product
  productId: string | null;
  productName: string | null;
  productImage: string | null; // Asset URL or null

  // price (resolved, pre-formatted strings for the geo's locale)
  price: string | null; // e.g. "39,00" for DE
  oldPrice: string | null;
  currency: string | null; // ISO 4217
  discount: string | null; // e.g. "51%" computed server-side

  // template
  templateId: string | null;
  placeholders: Record<string, string>; // Template.placeholders merged with overrides

  // i18n
  i18n: I18nDict;

  // tracking
  pixels: Record<string, string> | null; // from Landing.pixels Json
  postbacks: Record<string, string> | null; // from Landing.postbacks Json

  // meta
  seoMeta: SeoMeta | null;
  settings: Record<string, unknown>;

  // version snapshot info (for debugging / cache keys)
  versionId: string | null;
  resolvedAt: string; // ISO datetime
};

export type SeoMeta = {
  title?: string;
  description?: string;
  ogImage?: string;
  canonical?: string;
};

export type LandingStatus = "DRAFT" | "REVIEW" | "PUBLISHED" | "ARCHIVED";

export type LegacySource = "UPLOAD" | "GIT" | "URL"; // match your enum exactly
```

## Acceptance criteria

- `pnpm --filter <types-package-name> build` produces `dist/index.js` +
  `dist/index.d.ts`.
- `LandingContext.geoId` is `string`, NOT `geoCode` — matches real schema.
- `Landing.settings` is accessed as `Record<string, unknown>` — matches the Json
  Prisma type.
- `tsc --noEmit` passes in every workspace that imports from this package.
- No Prisma Client imports anywhere in `packages/types`.

## Out of scope

- Implementations / resolver logic (Phase 3.3).
- React components (Phase 3.1).
