# Phase 0 · Step 5 — Audit log

## Context

`AuditLog` model exists (529 rows) and `AuditAction` enum is defined. Audit rows
are currently written manually and inconsistently across services. This step
adds a transparent NestJS interceptor so every future mutating endpoint logs
automatically — no developer action required per route.

## Goal

A globally-registered `AuditInterceptor` that captures every 2xx response to
`POST` / `PATCH` / `PUT` / `DELETE` and writes one `AuditLog` row using the
existing model fields and existing `AuditAction` enum values.

### `apps/api/src/audit/audit.interceptor.ts`

```typescript
@Injectable()
export class AuditInterceptor implements NestInterceptor {
  constructor(private readonly prisma: PrismaService) {}

  intercept(context: ExecutionContext, next: CallHandler): Observable<unknown> {
    const req = context.switchToHttp().getRequest();
    const method = req.method as string;

    if (!["POST", "PATCH", "PUT", "DELETE"].includes(method)) {
      return next.handle();
    }

    // Snapshot entity state BEFORE handler runs (for diff on PATCH/PUT)
    const beforeP = this.snapshotBefore(req);

    return next.handle().pipe(
      tap((responseBody) => {
        // Fire-and-forget: do NOT await here — must not delay HTTP response
        setImmediate(async () => {
          try {
            const before = await beforeP;
            await this.write(req, responseBody, before);
          } catch (err) {
            // Audit failure MUST NOT affect the response
            console.error("[AuditInterceptor]", err);
          }
        });
      })
      // Do NOT catch here — let errors propagate so 4xx/5xx are NOT logged
    );
  }
```

### `apps/api/src/audit/audit.service.ts`

Buffered writer — collects entries for 50 ms then bulk-inserts:

```typescript
@Injectable()
export class AuditService {
  private buffer: Prisma.AuditLogCreateManyInput[] = [];
  private timer: NodeJS.Timeout | null = null;

  constructor(private readonly prisma: PrismaService) {}

  record(entry: Prisma.AuditLogCreateManyInput): void {
    this.buffer.push(entry);
    if (!this.timer) {
      this.timer = setTimeout(() => this.flush(), 50);
    }
  }

  private async flush(): Promise<void> {
    this.timer = null;
    if (!this.buffer.length) return;
    const batch = this.buffer.splice(0);
    await this.prisma.auditLog.createMany({
      data: batch,
      skipDuplicates: true
    });
  }
}
```

## Acceptance criteria

- `POST /v1/products` (once implemented in Phase 1.1) creates 1 `AuditLog` row.
- `GET /v1/products` creates 0 `AuditLog` rows.
- A 422 validation error creates 0 `AuditLog` rows.
- `GET /v1/audit?entity=Product` returns the row from bullet 1.
- `diff` field is a valid RFC 6902 JSON Patch array.
- All 529 existing `AuditLog` rows remain untouched.
- No new columns are added to `AuditLog` in this step.
- No new values are added to `AuditAction` enum in this step.
- Interceptor p50 overhead < 5 ms (async fire-and-forget verified by unit test —
  handler resolves before `auditLog.create` is awaited).
